# Predictive Analytics Using Historical Data

## Project Overview

This project focuses on forecasting future sales trends using historical sales data from the Superstore dataset. A Linear Regression model was developed to predict future sales, evaluate model performance, and support data-driven business decision-making.

## Objectives

* Clean and preprocess historical sales data
* Build a predictive model using Linear Regression
* Forecast future sales trends
* Evaluate model accuracy using R² Score
* Visualize historical and predicted sales trends
